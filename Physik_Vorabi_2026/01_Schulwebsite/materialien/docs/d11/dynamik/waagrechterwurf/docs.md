## Aufgabe 1: Hilfs-Paket

Ein Flugzeug lässt Hilfspakete ohne Fallschirme fallen und der Luftwiderstand wird vernachlässigt.

**Berechne** die Entfernung zum Zielpunkt bei welcher das Flugzeug ein Paket abwerfen muss, wenn das Flugzeug mit einer Geschwindigkeit von 540 km/h in einer Höhe von 680 m fliegt.

## Aufgabe 2: Räuber im Mittelalter

Ein paar Räuber wollen einen Pferdewagen aufhalten. Dazu wollen Sie von einer Bergkante einen Felsbrocken auf den Wagen fallen lassen. Die Bergkante ist 32 m hoch. Der Pferdewagen fährt mit 37 km/h durch den Wald.

In welcher Entfernung zum Auftreffpunkt müssen die Räuber eine Markierung setzen, damit sie den Felsbrocken im richtigen Moment fallen lassen.
